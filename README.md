# Prompt Library

你给 AI 写 prompt，但它总是回一些"看起来对但用不上"的东西？

可能不是你写得不对——是缺一个框架。

这里有 5 个 prompt，每个都经过真实场景迭代打磨。不是堆砌技巧，是沉淀了方法论——拿过去就能用。

详细用法 → [USAGE.md](USAGE.md)

## 设计理念

每个 prompt 的设计都有明确边界：

- **不堆砌技巧**：只有一个核心机制，做深做透。拿来就能用。
- **有交互流程**：不是"贴进去就出结果"——每个 prompt 内置了跟你的对话协议。它会先确认你的意图，再给出答案。
- **可迭代**：每个 prompt 都标注了版本号，改了能追溯。
