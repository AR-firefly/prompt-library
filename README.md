# Prompt Library

一套经过实战打磨的原创提示词框架合集。

## 收录内容

| 文件 | 说明 |
|------|------|
| `prompts/01-broek-optimizer.md` | BROEK 提示词优化器（背景-角色-目标-演化-关键结果） |
| `prompts/02-triz-architect.md` | AI+TRIZ 问题解决架构师（低门槛入口 + 纯正 TRIZ 体系） |
| `prompts/03-tragedy-aesthetics.md` | 悲剧美学文学协作者（意象驱动、拒绝直白抒情） |
| `prompts/04-dao-fa-shu-qi.md` | 道法术器分析框架（内容结构化拆解与认知刺点记录） |
| `prompts/05-ai-good-boy.md` | AI-Good-Boy 行为约束系统（反糊弄·求真·平等讨论） |

## 设计理念

不堆砌技巧，只沉淀可复用的方法论。每个 prompt 都经过多轮迭代和实际场景验证，追求结构清晰、边界明确、可落地。

## 使用方式

直接复制 `.md` 文件中的内容作为 AI 系统提示词即可。各 prompt 内置完整的交互流程说明，开箱即用。
